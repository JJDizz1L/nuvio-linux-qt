Hard-won facts recorded this session (do not relearn):

1. **LC_NUMERIC landmine:** QGuiApplication internally runs `setlocale(LC_ALL,"")`; afterwards `mpv_create()` returns NULL unless `setlocale(LC_NUMERIC,"C")` is re-applied *post-construction* (main.cpp does; probe-reproduced standalone).
2. **Logging routing:** CachyOS/omarchy Qt sends qC* output to journald, not stderr. Gate/harness FATALs use raw `fprintf(stderr,...)`; verbose categories forced via `applyMpvDebugEnv()` (`nuvio.*=true`). Read verdicts: `journalctl --user -f | grep -E 'SMOKE|decoder:'`.
3. **QT_QPA_PLATFORM=offscreen cannot drive the GL scenegraph**: render context never created, smoke stalls pre-VO. Use a real session or xvfb-run wrapper.
4. **Embedding order contract:** mpv refuses VO open without render context ⇒ early `play()` parks the request (`m_pendingUrl`) flushed by `notifyRenderContextReady()` queued from renderer success. Removing parking reintroduces "No render context set" fatal-at-load.
5. **FLIP_Y:** direct-FBO path needs `0` (user-verified upright); old readback line used `1` (pixel-memcpy semantics differ).
6. **QML types must not be `final`** (QQmlElement<T> derives); logging categories are header-inline functions (GNU ld single-pass archive trap); accessors use parentheses in plain code (`lcFoo()`), macro names only inside qC* macros.
7. **System note:** machine runs CachyOS-rebuilt pkgs (znver4 repos); vanilla `extra/mpv` swapped in + pinned via `/etc/pacman.conf IgnorePkg = mpv` (A/B showed the anomaly persists ⇒ CachyOS build NOT implicated). ffmpeg/libplacebo/libass/fribidi/harfbuzz/qt6-declarative remain CachyOS builds (documented risk if later anomalies appear).
